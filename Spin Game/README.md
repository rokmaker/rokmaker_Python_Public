# Round Slot · 라운드 슬롯

## 두 프로젝트
- **범용 Round Slot**: 현재 폴더의 `실행.bat`. 각 라운드가 완전히 독립적인 무작위 추첨입니다.
- **PoE2 EXILE SLOT**: `PoE2 실행.bat` 또는 `poe2-slot/실행.bat`. 전직 → 무기 구성 → 무기 조건에 맞는 스킬 젬을 뽑습니다. 별도 프로젝트이며 저장 공간도 분리됩니다. 상세 안내는 [PoE2 README](poe2-slot/README.md).

`실행.bat` 또는 `index.html`을 더블클릭하면 기본 브라우저에서 열립니다. 최신 Chrome/Edge를 권장합니다. Python 설치나 서버 실행은 필요 없습니다.

## 사용법
1. 왼쪽에서 프리셋을 선택하거나 ＋ 버튼으로 추가합니다.
2. 라운드를 선택하고 이름과 후보를 입력합니다. 후보는 한 줄에 하나씩 입력합니다.
3. 추가/삭제 및 위로/아래로 버튼으로 라운드를 구성합니다.
4. 돌리기를 누르면 위에서 아래로 슬롯이 움직이며 하나를 선택합니다.
5. 다음 미완료 라운드로 이동합니다. 모든 라운드를 완료하면 최근 기록에 조합이 남습니다.

## 저장 및 추첨 규칙
- 프리셋과 최근 완료 기록 50개는 현재 브라우저에 자동 저장됩니다.
- 진행 중인 조합은 새로고침, 프리셋 전환, 라운드 설정 변경 시 초기화됩니다.
- 다른 라운드 선택만으로는 진행 결과가 초기화되지 않습니다.
- 후보는 앞뒤 공백과 빈 줄을 제거하고, 동일한 이름의 중복 항목은 하나로 처리합니다.
- 각 후보의 당첨 확률은 동일합니다. 당첨 결과는 애니메이션 시작 전에 결정됩니다.
- 라운드 간 추첨은 독립적이며, 라운드 간 중복 당첨은 가능합니다.
- 프리셋 100개, 프리셋당 라운드 100개, 라운드당 후보 1,000개, 항목당 200자까지 지원합니다.
- 내보내기는 모든 프리셋을 JSON으로 저장합니다. 가져오기는 기존 목록에 프리셋을 추가합니다. 완료 기록은 내보내기에 포함하지 않습니다.
- 브라우저 데이터 삭제, 브라우저 변경, 파일 위치 변경 시 저장 정보가 유지되지 않을 수 있습니다. 중요한 프리셋은 파일로 내보내세요.

## 구현
HTML/CSS/JavaScript로 작성된 로컬 앱입니다. 빌드 및 외부 라이브러리 의존성 없이 실행됩니다. 시스템의 모션 감소 설정을 따릅니다.
