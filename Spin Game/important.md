# 재개 시 참고

- 2026-09-07: 두 프로젝트로 분리. 범용 코드는 현재 폴더 그대로, PoE2 전용은 독립 `poe2-slot` 폴더. 루트의 `PoE2 실행.bat`으로도 실행 가능. 서로 저장 키를 공유하지 않음.

- 요청: 원형 대신 위에서 아래로 도는 슬롯, 여러 라운드, 여러 프리셋.
- 구현: index.html / style.css / app.js. 실행.bat 더블클릭으로 실행.
- 외부 통신 및 설치 없이 동작. 프리셋/완료 기록은 브라우저 localStorage, 프리셋 백업은 JSON.
- 설정 수정 시 진행 결과 초기화, 완료 기록 유지. 프리셋 이름만 수정할 때는 진행 결과 유지.
- 후보는 중복 제거 후 동일 확률. 가중치 및 라운드 간 제약은 구현하지 않음.
- 다음 확인: 실제 브라우저에서 애니메이션 정지 위치, 작은 화면 레이아웃, 새로고침 후 저장 복원, JSON 다운로드/업로드.
- 브라우저 도구의 file URL 보안 차단으로 UI 검증은 미완료. 자동 상태 전환 테스트 통과와 실제 UI 검증을 구분할 것.
