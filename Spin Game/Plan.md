# Round Slot 구현 계획

## 프로젝트 분리 · 2026-09-07
- 범용 앱은 완전 무작위 방식 그대로 유지.
- PoE2 조건 연동 추첨은 별도 `poe2-slot` 프로젝트에 구현. 상세 계획과 검증 결과는 해당 폴더의 Plan.md 참고.

## 목표
세로 슬롯 애니메이션으로 라운드별 후보를 추첨하는 로컬 웹 앱.

## 결정
- HTML/CSS/JavaScript 사용. 설치나 서버 없이 index.html 실행.
- 프리셋마다 라운드 목록과 후보 목록 저장.
- 브라우저 localStorage 자동 저장 및 JSON 파일 백업 지원.
- 각 라운드는 독립적인 동일 확률 추첨. 결과 기록은 최근 50회 유지.

## 구현 순서
1. 슬롯 화면, 프리셋 및 라운드 편집 구현.
2. 회전 애니메이션, 결과 기록, 파일 입출력 구현.
3. 동작 검증 및 사용 안내 갱신.

## 결과 · 2026-09-07
- 첫 버전 구현 완료. 사용법은 README.md 참고.
- node --check app.js 및 node test.cjs 통과.
- 상태 전환 테스트: 전체 라운드 진행, 후보 내 당첨, 기록 중복 방지, 초기화, 중복 후보 정리, 빈 후보, 순서 변경, 프리셋 복제 독립성, JSON 검증/왕복, 저장 호출, 난수 범위 확인.
- 실제 브라우저 테스트는 로컬 파일 URL 접근이 도구 보안 정책으로 차단되어 미완료. 시각적 완성도 및 브라우저 파일 저장/다운로드 동작은 아직 확인하지 못함.
