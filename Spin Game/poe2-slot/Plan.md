# PoE2 Slot 계획

## 목표
범용 Round Slot과 독립된 PoE2 전용 앱. 직업/어센던시 → 무기 구성 → 사용 조건에 맞는 스킬 젬 순으로 추첨.

## 구조
- 이 폴더만 복사해도 실행되는 별도 프로젝트. 상위 범용 앱 코드/저장 키는 변경하지 않음.
- 독립 HTML/CSS/JavaScript, 데이터 파일과 규칙 엔진 분리.
- 0.5.5 대상. 공개 데이터의 버전 및 획득 가능 여부를 확인하고 미확인 항목을 구분.
- 무기군별 Gemcutting 분류와 장비 조건을 함께 적용. 무기 제한 없는 주문도 무기군을 넘어 섞지 않음.
- 고유무기 부여 스킬은 해당 장비 구성에만 추가하고 필수 고유무기 및 발동 조건을 표시.
- 사용 조건 안내를 표시. 빌드 성능이나 현재 캐릭터의 레벨/능력치를 보증하는 도구가 아님.

## 순서
1. 데이터 출처 확인 및 후보/조건 정리.
2. 독립 UI, 연동 추첨, 저장/기록 구현.
3. 규칙 전수 검사와 상태 전환 테스트, 문서 갱신.

## 완료 · 2026-09-07
- 독립 앱 구현: 전직 22개, 무기 구성 15개, 일반 젬 182개 + 고유무기 부여 스킬 19종.
- PoE2DB 일반 젬 절단 목록과 개별 무기 조건 수집. 부적 형태 제한 적용.
- 프리셋 3종, 후보 검색, 기록/진행 자동 저장, 결과 복사, 기록 내보내기.
