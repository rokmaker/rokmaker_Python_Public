# EXILE SLOT · PoE2 전용 조합 추첨

범용 Round Slot과 독립된 프로젝트입니다. **이 폴더의 `실행.bat` 또는 `index.html`을 더블클릭**하세요. 브라우저만 있으면 실행되며, Python·Node 설치나 서버 실행이 필요 없습니다. 이 폴더만 다른 위치로 복사해도 앱이 실행됩니다.

## 세 라운드
1. 직업 + 어센던시: 8개 직업에 속한 22개 어센던시에서 선택.
2. 무기 구성: 한손/양손 철퇴, 방패, 활, 석궁, 육척봉, 주문용 무기, 부적 등 15개 구성에서 선택.
3. 스킬 젬: 선택한 무기 구성과 호환되는 젬 중 하나를 선택.

현재 일반 스킬 젬 절단 목록의 **182개 젬 + 확인된 고유무기 부여 스킬 19종**을 수록했습니다. 공격뿐 아니라 저주·공물·보조 역할의 스킬도 포함됩니다. 전체 목록, 공격, 주문/소환수 프리셋을 선택할 수 있습니다.

## 사용법
- 돌리기 → 다음 라운드 → 돌리기로 진행합니다.
- 라운드 버튼을 누르면 해당 라운드부터 다시 뽑습니다. 뒤의 결과는 함께 초기화됩니다.
- 현재 추첨 후보 확인을 펼치면 후보 검색과 원문 링크를 볼 수 있습니다.
- 세 라운드가 끝나면 결과와 추가 사용 조건이 표시됩니다.
- 조합 복사, 최근 기록 50개, 기록 JSON 내보내기를 지원합니다. 기록 파일의 앱 내 재가져오기는 지원하지 않습니다.
- 회전 속도 변경 및 애니메이션 생략을 지원합니다. OS의 모션 감소 설정도 따릅니다.

## 호환 판정 범위
- 어센던시는 기본 직업과 묶어서 뽑습니다. 직업 테마를 이유로 특정 무기나 일반 주문을 제한하지 않습니다.
- 젬 절단 메뉴의 무기군 분류와 장비 요구 조건을 함께 적용합니다. 예: 활 전용 젬은 석궁에서 제외, 방어도 방패 전용 젬은 버클러에서 제외, 초과 충전 강타는 양손 철퇴에서만 선택.
- 부적은 선택된 형태의 전용 젬과 해당 고유부적의 유지형 부여 스킬을 뽑습니다. 용암 충격은 곰 형태에만 포함합니다.
- 활/석궁/철퇴/창/육척봉은 해당 절단 분류로 제한합니다. 석궁에 구형 번개·전기불꽃은 나오지 않습니다.
- 주문용 마법봉/지팡이는 별도 절단 무기 탭이 없어 원소·비술·원시 분류 중 장비/형태 조건을 만족하는 항목을 묶습니다. 이는 앱의 분류 정책입니다.
- 고유무기 스킬 당첨 시 표시된 고유무기를 반드시 장착하세요. 자동 발동·유지형 효과는 별도 공격이나 충전 준비가 필요할 수 있으며 조건을 함께 표시합니다.
- 레벨, 힘·민첩·지능, 마나·생명력·정신력, 시신·소환수·충전·영광 등 개별 스킬 조건은 플레이어가 충족해야 합니다. 완성 화면의 안내와 젬 원문을 확인하세요.
- 전직 패시브의 세부 선택, 고유 아이템 효과, 보조 젬 연결, 장비별 수치 및 빌드 성능은 계산하지 않습니다. 사용할 수 있는 무기/젬 조합의 시작점을 뽑는 도구입니다.
- 메타 젬에 넣을 추가 스킬은 별도 선택이 필요합니다.

## 확률
각 라운드에서 표시된 후보 항목은 동일 확률입니다. 1라운드는 어센던시별 동일 확률, 2라운드는 무기 **구성별** 동일 확률입니다. 따라서 어센던시 수가 다른 기본 직업이나 구성이 여러 개인 무기군의 합산 확률은 동일하지 않습니다. 전체 조합을 한꺼번에 균등 추첨하는 방식도 아닙니다.

- 일반 스킬 젬 절단 목록과 개별 젬 페이지를 대조한 스냅샷입니다. 과거 클라이언트에서 추출한 고정 버전 데이터나 인게임 전수 검증 결과는 아닙니다.
- 이번 고유무기 추가 범위는 명시적 레벨 스킬 부여 옵션의 별도 스킬 19종입니다. 일반 젬 중복과 무기 베이스 기본 스킬은 추가하지 않았습니다. 전직 전용 스킬, 보조 젬, 리그 룬 스킬, 개발용 항목도 제외합니다. [SOURCES.md](SOURCES.md)에 출처와 제외 기준을 기록했습니다.
- 데이터는 앱에 포함되어 있어 실행 시 인터넷을 사용하지 않습니다. 정보 링크를 열 때만 웹사이트로 이동합니다.
- 진행 중인 선택, 프리셋, 회전 속도, 완료 기록은 `poe2-exile-slot-v1` 키에 저장됩니다. 범용 앱의 `round-slot-v1`과 완전히 분리되어 있습니다.
- 브라우저 데이터 삭제, 파일 위치 변경, 브라우저 변경 시 저장이 유지되지 않을 수 있습니다. 중요한 완료 기록은 파일로 저장하세요.
- 규칙 변경으로 호환되지 않는 진행은 유효한 앞 라운드까지 복구합니다. 완료 기록은 “이전 규칙” 표시로 보존합니다.
- 저장 불가 시에도 추첨할 수 있습니다. 새로고침 시에는 진행 내용이 사라질 수 있습니다.

## 개발 및 검증
- `data.js`: 한글/영문 이름, 무기 요구 조건, 출처, 안내.
- `engine.js`: 순차 선택, 호환 조건, 재추첨, 저장 데이터 검증.
- `app.js`: UI, 회전, 저장, 기록.
- `node test.cjs` 또는 `npm test`: 규칙 및 UI 상태 전환 자동 검사. Node는 개발 테스트에만 필요합니다.
- 18,810개 프리셋/어센던시/무기/젬 경로 검사 및 오류·저장·복원 검사 통과.
- 실제 브라우저 화면, 애니메이션, 파일 다운로드와 클립보드 권한은 아직 시각적으로 검증하지 못했습니다. 이전 로컬 파일 열기 검증은 브라우저 도구의 URL 보안 정책으로 차단되었습니다.
